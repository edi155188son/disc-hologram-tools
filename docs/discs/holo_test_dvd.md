# holo_test.iso — 真波前全息診斷盤（2026-11-21）

holo_true 的真全息只看到輪廓、沒有細節。這張盤把各環節拆開，每塊只改一個變數。
8 塊 12 mm 方塊，在半徑 41 mm 繞一圈、每 45° 一塊，圖片上方都朝外。

## 怎麼認
三塊空白方塊相連（P0、P1、P2），接著五塊有圖（P3–P7）。
- 從 P7（臉）往下一塊走：P0 → P1 → P2 → P3 → … → P7。
- P6 是兩條直線，最好認；P5 是唯一有深度的臉。

| 塊 | 內容 | 要看什麼 |
|---|---|---|
| P0 | 純 CC67 序列光柵（1.233 µm，550 nm 在 26.5°） | 亮度與顏色的基準，跟光柵卡同類 |
| P1 | 貪婪法做的同一個 1.233 µm 光柵（理想打分） | **和 P0 一樣亮、一樣純色嗎？** 一樣 → 逐碼字相位控制在實體上成立 |
| P2 | 貪婪法 1.300 µm（沒有任何單一序列是這個週期），抗燒短打分 | 有沒有一個乾淨的顏色帶、角度比 P0 略小 |
| P3 | 臉，平面 z = 0，**平滑相位**（無擴散） | 最基本的影像：看得到臉嗎？雜斑少、顏色隨角度整片變 |
| P4 | 臉，平面 z = 0，**隨機相位**（擴散），抗燒短 | 和 P3 比：看得到臉嗎？雜斑多少 |
| P5 | 臉，深度 ±3 mm，擴散，抗燒短 | 和 holo_true 同類（改良版）：細節有沒有比 holo_true 好 |
| P6 | 兩條直線：左邊浮在盤面上方 4 mm，右邊在下方 4 mm | **左右移頭時兩條線往相反方向移動嗎？** 能對焦到不同深度嗎？ |
| P7 | 同 P4，但用理想打分（不抗燒短） | 和 P4 比：抗燒短有沒有用 |

背景改寫 0.853 µm 光柵（在 27° 只對應紫外光），應該比 holo_true 的藍紫背景暗。

## 看法
跟光柵卡一樣：手機手電筒在眼睛側邊約 27°、同高，把要看的那塊轉到 12 點鐘，左右移頭。
每塊各拍一張（能錄影更好，P6 一定錄）。

## 判讀
- P1 ≈ P0 但 P3 看不到臉 → 光柵層面沒問題，問題在影像編碼。
- P1 遠暗於 P0 → 貪婪法挑出的碼字在實體上不能維持相位（燒錄物理），要改方法。
- P3 有臉但 P4/P5 沒有 → 問題在隨機相位（擴散）和雜斑，改用平滑相位或部分擴散。
- P6 兩線反向移動 → 真波前深度成立。
