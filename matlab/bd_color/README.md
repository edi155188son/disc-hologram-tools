# color_bd：BD-R 彩色彩虹全像測試盤（2026-11-25）

## 做法
- 每塊區塊放三個顏色通道（R、G、B），各用自己的載波週期 Λ_c = λ_c / sin θ0。
  在設計觀看角 θ0，紅通道繞射紅光、綠通道繞射綠光、藍通道繞射藍光 → 白光下看到彩色的臉。
- 三個通道在同一塊面積上**頻率多工**：BdAmp 對每個 byte 計算 S = Σ conj(e_c)·exp(i2πv/Λ_c)，再用雙相位編碼（相鄰軌 arg S ∓ acos|S|，處處 50% 亮）。雙相位對 +1 階是線性的，三色互不干擾，也不會出現交錯排列的側帶鬼影。
- 每個通道：水平 ±8°（左右視差）、垂直 ±δ（彩虹的「狹縫」，決定顏色純度與看得到正確顏色的上下範圍），深度 ±4 mm，12 層。
- 彩色的來源是 avatar3d 的彩色貼圖（每個通道的振幅 = sqrt(線性亮度)）。

## 模擬結果（`color_sim.m`、`color_sim_LED.png`、`color_metrics_*.txt`）
- 0.8 mm 測試片（R、G、B、白四條）在 BD 格點上做雙相位編碼加 15% 不可控 byte，用白光 LED／平坦光譜、CIE 1931 → sRGB 算出眼睛看到的顏色。
- θ0 = 10–17.5°、δ = 1° 時，設計角度下紅、綠、藍都分得開，白色條接近白色。θ0 = 21° 時紅、綠通道幾乎消失（每週期只剩 4–5.5 軌），所以沒有放上盤。
- δ = 2° 顏色明顯變淡；δ = 0.5° 顏色最純，但比較暗。
- 上下移動 1° 整張臉的色調就會一起偏移（彩虹全像本來就是這樣），正確顏色只在大約 ±0.5–1° 內。
- 對比（`color_snr.m`，設計角度、單色）：單一通道約 25:1，三通道各色約 7:1（三色各只分到約 1/3 的光）。主要雜訊來源是那 15% 不可控的 byte。

## 產生 ISO
```
cd /d <WORK>\color_bd
BdAmp --inner 23.987042157339335 --outer 57.987960341783236 --dark 9E --light 22 --encoding dp --combine sum --steer-parity on --taper 1.5 --fields C1_R.bdaf,C1_G.bdaf,C1_B.bdaf,C2_R.bdaf,C2_G.bdaf,C2_B.bdaf,C3_R.bdaf,C3_G.bdaf,C3_B.bdaf,C4_R.bdaf,C4_G.bdaf,C4_B.bdaf,C5_R.bdaf,C5_G.bdaf,C5_B.bdaf,L1.bdaf,L2.bdaf,L3.bdaf,L4.bdaf,L5.bdaf --output color_bd.iso
```
- 欄位檔共約 18 GB，BdAmp 執行時需要約 20 GB 記憶體。
- BdAmp 已更新：`--combine sum`（同位置多個載波相加）和雙三次插值（interpV = 2）。舊指令照樣能用。
- 開頭的 self-check 必須是 0/2000。
- `--steer-parity on`（2026-11-25 新增）：校驗碼反解。區塊內的 LDC 校驗 byte 改成圖樣的一部分，由區塊外的背景 byte 反解；結束時印出「Parity steering … forced x/y」。容器測試 1,337,267 個受限校驗 byte，用 DiscImageStudio 的 LDC 編碼器重算後 100% 相符。模擬對比：單色 22 → 84、三通道各色 7 → 21。產生時間約多 60%。
- `--taper 1.5`：區塊邊緣 1.5 mm 的 cos² 振幅漸弱（壓低邊緣十字拖影）。
- 想要對照組，可以去掉這兩個選項另外產生一份。

## 觀看
- 白光點光源（手機手電筒、白光燈珠），暗房，光源放遠一點（50 cm 以上）會比較清楚。
- 每塊的臉都出現在光源鏡面反射點往碟片中心或外緣方向偏 θ0 的地方：區塊 1、2、5 約 14°，區塊 3 約 10°，區塊 4 約 17–18°。
- 上下慢慢移動，找到「頭髮、皮膚、耳機顏色正確」的高度；再往上或往下，整張臉會一起偏紅或偏藍。
- 要回報的項目：哪一塊顏色最正確、白色（或最亮的部分）是不是白的、哪一塊最亮、正確顏色的上下範圍多大。

## 沒做的：彩色全視差（FP）
- 全視差在白光下本來就會糊，彩色版需要三色窄頻光（RGB LED 或雷射）。
- 更麻煩的是每個通道都會繞射另外兩種顏色的光。以 θ0 = 13.7° 為例，會在主影像上下約 2–3° 處出現 6 個串色鬼影，而 ±8° 的視角範圍會和它們重疊。
- 要做的話只能把垂直視角縮到 ±1° 左右，那就等於彩虹全像了。所以這張先全部做彩虹版。
