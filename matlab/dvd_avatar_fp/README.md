# avatar_fp.iso — 頭像：全視差 vs 彩虹（徑向載波振幅全息，2026-11-24）

同一個頭像（avatar3d 的 texture + depth16）做成兩塊：
- **FP（全視差）**：完整二維波前，上下、左右都有視差。用**單色光**看。
- **RB（彩虹）**：HPO，只有左右視差，上下是顏色變化（跟 radial_app 的 C 區同做法）。用**白光**看。

產生：`avatar_fp.m`（MATLAB）→ `FP.hpo`、`RB.hpo`（DVDHPO1）→ `DvdDiffractionRings`。盤片 CMC MAG. AM3，sectors 2297888。

## 產生 ISO 與燒錄
```
cd /d <WORK>\DvdDiffractionRings-win-x64\publish
DvdDiffractionRings --pattern polar --sectors 2297888 --output avatar_fp.iso --raster FP.hpo,RB.hpo
```
兩個柵格各 545 MB，產生時約需 1.1 GB 記憶體。ImgBurn「Write image file to disc」，4x 以下。

## 設計
| | FP | RB |
|---|---|---|
| 位置 | r 44 mm、0°（半徑 36–52 mm） | r 44 mm、180° |
| 區塊 | 16 × 16 mm | 16 × 16 mm |
| 頭像 | 寬 15 mm，「上」朝外 | 同左 |
| 深度 | −4…+4 mm（臉中央最前、離盤面 4 mm；頭髮尖端在後） | 同左 |
| 視角 | 上下 ±3.5°、左右 ±3.5° | 左右 ±3.5° |
| 載波 | 直線徑向光柵，每 5 軌一週期（3.70 µm；532 nm 約 8.3°，550 nm 約 8.6°） | 同左 |

- 圖：頭像的黑色描線變成**亮線**（加粗到約 0.1 mm），其餘不發光。目前的編碼只用相位，振幅被忽略，所以填色會跟描線一樣亮、把畫面洗白（已試過，模擬見 `old_v1`、`old_v2`）。
- 載波用直線（不沿軌道彎）：16 mm 寬的區塊兩側軌道方向偏 ±10°，沿軌道彎的載波會讓兩側的光往不同方向跑，整張臉無法同時看到。直線載波在兩側跨軌的切線週期約 19 µm，加上物體本身的 ±3.5°，最細處約 6 µm（radial_app 的 B1 在 7.6 µm 清楚、B2 在 4.7 µm 已糊）。
- 物體用 16 層深度；全視差用 4 µm 格點的二維角譜傳播，彩虹用每 20 µm 一列的一維傳播。

## 怎麼看
**單色光源**：綠色 LED 手電筒，或手機手電筒前面貼一片綠色濾光片（玻璃紙也可以），放在眼睛旁邊、像點光源。**不要用雷射直接看**。

1. 暗房。區塊轉到 12 點或 6 點鐘方向（徑向 = 上下）。
2. 上下傾斜光碟，讓鏡面反光點移到區塊上方或下方約 8°，頭像應該出現。
3. **FP＋單色光**：上下、左右移動頭部（30 cm 外大約各 ±2 cm 的範圍），臉的輪廓／眼睛（前）和頭髮、耳機（後）應該互相錯開。上下錯開＝垂直視差，這是這張盤要驗證的新東西。
4. **FP＋白光**：應該會變成彩色的糊影（白光下全視差薄全息的物理限制）。
5. **RB＋白光**：清楚；上下移動顏色會變，左右移動有視差。
6. **RB＋單色光**：只在一個很窄的上下角度看得到，沒有垂直視差。

## 模擬（`FP_sim.png`、`RB_sim.png`）
只算中央 8 × 8 mm（codeword 網格、15% 不可控 byte）。FP：單色光 左／中／右／下／上 五個視角＋白光；RB：單色光 左／中／右＋白光。FP 的白光圖出現彩色鑲邊，RB 的白光圖是乾淨的單色——符合預期。

`old_v1\`、`old_v2\`（共約 2.2 GB）是前兩版，可以刪除。

# avatar_fill.iso — 填色版（振幅編碼，2026-11-24）

`avatar_fill.m`：同樣的兩塊（FPf、RBf，位置／大小／深度／載波都跟上面相同），但用原圖亮度（頭髮、皮膚有填色，描線是暗的），並加上**振幅編碼**（Lee 條紋寬度法）：每個載波週期裡亮的寬度 D = asin(a)/π，a 是歸一化的場強；a = 0 時整段是 A5（沒有載波），所以背景是全暗的 A5（線稿版是 92，兩者都不繞射）。

```
cd /d <WORK>\DvdDiffractionRings-win-x64\publish
DvdDiffractionRings --pattern polar --sectors 2297888 --output avatar_fill.iso --raster FPf.hpo,RBf.hpo
```

- 模擬（`FPf_sim.png`、`RBf_sim.png`）：臉的明暗、眼睛、頭髮的形狀都回來了，但整片是滿版的斑點（speckle）。這是隨機相位擴散的全息在同調光、小瞳孔下的必然現象，模擬是最壞情況（完全同調、0.6° 瞳孔）。
- 降低斑點：用**面積大一點、霧面**的單色 LED（例如 1 cm 的霧面燈，距離 50 cm），光源的角度越大斑點越弱；代價是深度方向稍微糊一點（±4 mm 深度 × 光源張角約 1°，約 0.07 mm）。白光看 RBf 時同理。
- 亮度：填色版每單位面積比線稿版的亮線暗（平均條紋寬度較窄），但發光面積大很多。
