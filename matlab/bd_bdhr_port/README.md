# BD-R 全息測試（BdHolo）

把 DVD-R 上測過的全息圖全部搬到 BD-R（單層 25 GB）。基於 DiscImageStudio 的 BD 引擎：每個 user byte 經 LDC 交錯 / BIS 之後的實際盤面位置都會算出來，產生器在那個位置對點陣圖取樣。

- `BdHolo`：`--inner --outer [--sectors 12219392] [--pitch-linear/-quadratic/-cubic] [--max-radius mm] --patches a.bdhr,b.bdhr,... --output x.iso`
  - `--max-radius`：ISO 只寫到這個半徑（檔案小、燒錄快，部分燒錄）。
  - byte：255 → 44（6T 多，「亮」），0 → AA（3T 多，「暗」），128 與區塊以外 → 每個 byte 隨機 AA/44。
- `.bdhr`：`BDHR1\0\0\0`、int32 N、double dx（mm）、double 中心半徑、double 角度（度），接著 N×N byte（列 = 半徑往外、行 = 切線方向）。
- `bd_disc1.m`：產生第一張盤的所有點陣圖與 `bd1_patches.txt`。
- byte 反差（1-7PP 平均 run 長度）：9E 2.59T（最短）、AA 3.09T、隨機 3.38T、44 5.16T（≈ 最長 5.21T）。這張先用 AA/44（DiscImageStudio 的快速路徑）；9E/44 留待之後比較。

## bd1_verbatim.iso（Verbatim BD-R 64099/64293）

參數：inner 23.987042157339335、outer 57.987960341783236 mm、12,219,392 扇區（DiscImageStudio 內建，沒有三次係數）；ISO 只寫到 r = 47.5 mm（約 15.1 GB）。每塊旁邊（切線反方向）有 4 mm 字母標記。

## bd2_probes.iso：診斷光柵（`--pattern probes`）

bd1 的外框是方的，但所有全息圖都看不到成像，只有 0 階周圍一大片帶彎曲條紋的散射。用三種光柵把可能原因分開（全部 44 / AA、50% 佔空比）：

| 環 | 半徑 mm | 光柵 | 週期 | 綠光 1 階 | 1 m 外離 0 階 | 方向 |
|---|---|---|---|---|---|---|
| P1 | 25.0–26.2 | 徑向（依半徑分帶） | 8 µm | 3.8° | 6.7 cm | 沿半徑 |
| P2 | 26.5–27.7 | 徑向 | 16 µm | 1.9° | 3.3 cm | 沿半徑 |
| P3 | 28.0–29.2 | 徑向 | 32 µm | 0.95° | 1.7 cm | 沿半徑 |
| P4 | 29.5–30.7 | 切線（沿軌道弧長，每軌相位自由） | 8 µm | 3.8° | 6.7 cm | 沿切線，被拉成徑向細線 |
| P5 | 31.0–32.2 | 切線 | 16 µm | 1.9° | 3.3 cm | 同上 |
| P6 | 32.5–33.7 | 切線 | 32 µm | 0.95° | 1.7 cm | 同上 |
| P7 | 34.0–35.2 | 切線 | 128 µm | 0.24° | 4 mm | 同上 |
| P8 | 35.5–36.7 | 放射狀（跨軌對齊） | 12 µm | 2.5° | 4.4 cm | 沿切線 |
| P9 | 37.0–38.2 | 放射狀 | 48 µm | 0.64° | 1.1 cm | 沿切線 |
| P10 | 38.5–39.3 | 全部 44 | — | — | — | 參考 |
| P11 | 39.6–40.4 | 隨機 | — | — | — | 參考 |

判讀：
- **P1–P3 沒有繞射點** → AA/44 的低頻反射率差太小（全息圖的亮度來源不存在），要換 byte 組合（例如 9E/44）。
- **P1–P3 有、P4–P7 沒有** → 交錯後的沿軌 byte 位置在 µm 等級不準（DiscImageStudio 的位置只是名目值）；P7（128 µm，接近一個 frame 144 µm）有而 P4–P6 沒有 → frame 內的 byte 順序錯。
- **P4–P7 有、P8–P9 拉成線** → 跨軌對齊不夠（BD 軌道多 2.3 倍）。
- 三種都有 → 問題在全息設計本身（例如 BD 的雜散比預期大），再回頭查。

**bd2 實測（2026-11-11）：** P1–P11 全部只看到同樣的 0 階雜斑 / 散射，連徑向光柵（P1–P3）都沒有繞射點 → AA/44 在綠光下的平均反射率幾乎相同（BD 的 3T / 6T pit 都小於波長），沒有可用來畫全息圖的亮暗差。沿軌位置模型與跨軌對齊目前無法判斷。所有環共同的散射是 BD 盤片結構本身的背景。

## bd3_palette.iso：BD byte 調色盤（`--pattern palette`）

徑向光柵、週期 16 µm（8 µm 一帶 ≈ 25 軌），只依賴兩個 byte 的平均反射率差。綠光 1 階 1.9°，1 m 外離 0 階約 3.3 cm，沿半徑方向（P1 有就代表 AA/44 其實有反差，只是 bd2 沒拍到）。使用任意 byte 的對應表 → 走單執行緒路徑，產生較慢（約 5 MB/s）。

| 環 | 半徑 mm | A / B | 想法 |
|---|---|---|---|
| P1 | 25.0–26.0 | AA / 44 | 對照組（bd2 看不到） |
| P2 | 26.3–27.3 | 9E / 44 | run 長度差最大（2.59T / 5.16T） |
| P3 | 27.6–28.6 | 9E / AA | 2T 對 3T |
| P4 | 28.9–29.9 | 9E / 隨機 | |
| P5 | 30.2–31.2 | 44 / 隨機 | |
| P6 | 31.5–32.5 | AA / 隨機 | |
| P7 | 32.8–33.8 | 9E / 22 | 另一個長 run byte |

9E 幾乎全是 2T（約 0.15 µm）pit，可能燒得很淺、接近空白，跟長 pit 的 44 配對反差最有機會。哪一環看得到 ±1 階、哪一環最亮，就是下一張全息圖要用的組合。

注意：ImgBurn 對小於 8.5 GB 的 ISO 會拒絕燒到 BD（「fits DVD-R DL」）。bd3_palette.iso 已在尾端補零到 9.06 GB（4,423,680 扇區，半徑 34.2 mm 以外，零經擾碼後等同隨機背景）。之後的小 ISO 都要補到 8.5 GB 以上。

**bd3 實測（2026-11-11）：** P1–P7 中只有 P4（9E/隨機）看不到 ±1 階，其他都有，**P7（9E/22）最清楚**。AA/44 其實也有反差，只是弱，bd1 / bd2 的訊號被盤片本身的干擾條紋淹沒了。9E 的平均反射率接近隨機資料；長 run 的 22 / 44 跟它差最多。

## bd4_9E22.iso：用 9E/22 重做診斷光柵＋全息（`--bytes 9E,22`）

DiscImageStudio 的快速路徑原本寫死 AA/44；本地版 `BluRayRunLengthMapping` 加了任意 byte 配對的建構子，速度維持約 100 MB/s。`--min-gb 8.6` 自動在尾端補零（ImgBurn 拒燒小於 DVD-R DL 的 BD 映像）。寫到 r = 57.5 mm（24.5 GB）。

- 內圈 25–40.4 mm：bd2 的診斷光柵 P1–P11（徑向 8/16/32、切線 8/16/32/128、放射狀 12/48 µm），全部改成 9E/22；**P10 現在是「全部 22」**，P11 是 9E/22 隨機混合。判讀表同 bd2。
- r = 45 mm（6 mm 雷射）：A F @0°、B「DVD」筆畫 @90°、H 深度刻度 @180°、C 笑臉 @270°。
- r = 51.5 mm（8 mm 白光）：E 心形 +3 @0°、F 圓環/星形 @120°、G 心形 +10 @240°。
- 字母標記在各塊切線反方向（點陣圖沿用 bd1，只改位置）。
