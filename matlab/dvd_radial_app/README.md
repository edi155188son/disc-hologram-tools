# radial_app.iso — 徑向振幅應用盤（2026-11-24）

依據 probes_radial 的結果（徑向振幅可細到單條軌、跨軌對準 ≲ 1 µm）設計。全部是 92/A5 二值振幅，不受 frame 正負號影響。
產生：`radial_app.m`（MATLAB）→ 7 個 DVDHPO1 極座標柵格 → `DvdDiffractionRings`。盤片 CMC MAG. AM3，sectors 2297888，CMC 標定參數（exe 預設值）。

## 產生 ISO 與燒錄

```
cd /d <WORK>\DvdDiffractionRings-win-x64\publish
DvdDiffractionRings --pattern polar --sectors 2297888 --output radial_app.iso --raster A1.hpo,A2.hpo,B1.hpo,B2.hpo,R0.hpo,C1.hpo,C2.hpo
```
ImgBurn「Write image file to disc」，4x 以下。柵格合計約 700 MB，產生時會全部載入記憶體。

## 怎麼看

### 雷射區塊（A1、A2、B1、B2、R0）
跟以前的 F 全息一樣：綠光雷射接近垂直打在區塊上，在盤面上方約 400 mm 處、依上表的偏移位置用白紙找 F 的實像。另一側會有共軛像（發散、模糊）。
重點：
1. **A1／A2 的 F 有沒有往徑向（外側）成像**：這是第一次用寫入的徑向載波做大角度偏轉成像。A2 是 2.3 軌一週期，最有挑戰。
2. **B2 比 B1 糊多少**：判斷切線約 4.7 µm 的條紋能不能用。
3. **跟 R0 比亮度**。

### 白光區塊（C1、C2）
1. 暗房，點光源（手機手電筒）放在眼睛旁邊。
2. 把區塊轉到 12 點或 6 點鐘方向（徑向 = 上下）。
3. 上下慢慢傾斜光碟，讓鏡面反光點移到區塊的**上方或下方**：C1 約 8.5°、C2 約 14.3°（綠光的角度）。區塊裡應該出現圓環和 X。
4. **上下移動頭部 → 顏色變化**（色散在徑向）；**左右移動頭部 → 圓環和 X 相對移動**（視差在切線）。這就是要驗證的「視差和色散分到兩個方向」。
5. 反光點在另一側時看到的是深度相反的共軛像。
6. 不要跟這兩個混淆：切線方向約 15° 的 92 自身光柵階（一條徑向的線），以及徑向約 46° 的溝槽彩虹。

## 模擬（`*_sim.png`）
- A/B/R：codeword 網格（每軌 × 每 byte）上加 15% 不可控 byte 雜訊，Fresnel 傳播到 Z = 400 mm。F 都在預期位置成像。
- C：徑向一階、0.6° 瞳孔，切線視角 −4°／0°／+4° 三張；圓環（前）和 X（後）相對移動。圖的縱橫比沒有校正，圓環看起來是橢圓。
- 舊版（每 4 軌載波、F 沒有抖動）在 `old_v1\`，可以刪除。每 4 軌時第 3 階諧波會剛好混疊回 +1 階，造成重影，所以 C1 改成 5 軌。
