# avatar_bd2：BD-R 頭像第二版（2026-11-24）

## 跟第一版的差別
| | v1 (`avatar_bd`) | v2（這版） |
|---|---|---|
| 編碼 | Lee（條紋寬度 = 振幅） | **雙相位**：相鄰軌交替 arg e ± acos\|e\|，處處 50% 亮 |
| 碟面上的「照片」 | 有（平均反射率就是臉） | **沒有**（平均反射率均勻，看到的臉只來自全像） |
| 載波 | 11 軌 3.52 µm（532 nm 8.7°） | **7 軌 2.24 µm（532 nm 13.7°；450 nm 11.6°、650 nm 16.9°）** |
| 視角錐 | ±3.5° | **±8°** |
| 深度 | ±6 mm | **±9 mm** |
| 鼻尖 vs 耳朵的相對位移 | 約 ±0.4 mm | **約 ±1.3 mm**（約 3 倍） |
| 識別 | 無 | 每塊右側（+角度方向）有 6 mm 字母 **F** / **R**（全亮 byte，平面印刷） |
| 每個視角的亮度 | 1 | 約 1/3–1/5（視角面積變大） |

區塊位置和大小不變：FP @ 0°、RB @ 180°，r = 41 mm，31 × 31 mm，臉寬 30 mm。

## 產生 ISO（BD-R，Verbatim BA5）
```
cd /d <WORK>\avatar_bd2
BdAmp --inner 23.987042157339335 --outer 57.987960341783236 --dark 9E --light 22 --encoding dp --fields FP.bdaf,RB.bdaf,label_F.bdaf,label_R.bdaf --output avatar_bd2.iso
```
- 約 25 GB、約 2.5 GB 記憶體；開頭會印「track parity self-check: 0/2000」，不是 0 就先停下來告訴我。
- BdAmp 已更新（加了 `--encoding dp` 和字母用的平面模式），舊指令照樣能用。
- 換 BD-RE（Verbatim 43614）時：把 `--inner/--outer` 換成 RE 的值並加上三個 `--pitch-*`（見對話）。

## 觀看
- 碟面在一般燈光下應該只看得到 F / R 字母和兩個顏色均勻的方塊，**看不到臉**；臉只在全像角度出現。
- 全像角度：光源鏡面反射點往碟片中心或外緣方向偏約 14°（綠光），±8° 內都看得到。
- RB：白光，上下傾斜換顏色，左右看視差。FP：綠光燈珠，上下左右都有視差。
- 判斷立體感：盯著鼻尖和耳朵／頭髮邊緣的相對位置，左右移動應該明顯錯開。

## 模擬（`FP_sim.png`、`RB_sim.png`，中央 4 mm，BD 格點 + 15% 不可控 byte）
- 最右一格是平均反射率：均勻灰，確認沒有「照片」。
- RB 換視角時線條位移明顯比 v1 大。FP 在這個 4 mm 裁切裡很淡（深度加大、細節攤開），實際看整張臉為準。

## 風險
- 亮度降為 v1 的約 1/3–1/5；v1 已經「非常不明顯」，這版要在暗房、強光源（1W 燈珠）下看。
- 雙相位第一次上盤：它對跨軌對位的要求和 v1 相同（載波都在半徑方向），但振幅完全靠相鄰兩軌相加抵消，對 9E/22 的實際反差和燒錄記號長度的偏差比較敏感。如果 v2 完全看不到臉，下一版改回 Lee 編碼、保留 ±8° 視角與 ±9 mm 深度做對照。
